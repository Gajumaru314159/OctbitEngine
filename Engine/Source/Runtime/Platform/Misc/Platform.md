Platform {#Platform}
===================

Platformモジュールでは、特定のプラットフォームでのみ使用できる機能を実装をします。
プラットフォーム毎の実装は動的に読み替えられるものではないため、1つのプロジェクト内に全てのOSの実装を記述します。

* Dialog
    * FileOpenDialog
    * FileSaveDialog
    * FolderOpenDialog
* DLL
* System


## 実装変更の提案
1つのプロジェクトに全ての実装に含めるのではなく、Platformモジュールにはヘッダーのみ(宣言のみ)を含めて、各OSの実装はプラグインとして実装する案を検討中です。
ビルド時はビルド予定のプラットフォームのライブラリのみをビルドに含めるようにします。

* 問題点
    * プラットフォームごとにフォルダが別れてしまうため、プラットフォームごとの実装の比較が難しくなる
