詳解

任意の型を保持するクラス

型情報を保持し、型情報に基づいて値を取得、設定できます。 内部値はconstかと、参照型かを保持します。

◆ Any()

ob::core::Any::Any ( const Any &  other)
inline

コピーコンストラクタ

コピー代入されたAnyオブジェクトは常に参照Anyオブジェクトとして扱われます。 　明示的にコピーする必要がある場合は copy() を使用してください。 コピー元のAnyオブジェクトが破棄された場合はコピー先のAnyオブジェクトは無効な状態になります。

AnyオブジェクトにAnyオブジェクトを書き込む

通常の代入演算子は内部オブジェクトを変更しないため、内部オブジェクトを変更する場合はこの関数を使用してください。 　　　　　 int value = 0; Any a = value; a = Any(10); assert(value==0); a.assign(Any(10)); assert(value==10);

Anyオブジェクトに値を代入する

以下のタイプのAnyオブジェクトに対して代入は無視されます。

  • 空のAnyオブジェクト
  • 書き込み不可のAnyオブジェクト
  • 異なる型の代入
