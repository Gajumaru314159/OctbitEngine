メモリ管理
==========

RenderSceneはGraphicsがメモリ管理をし、それ以外の外部からはHandleを経由してアクセスします。
インスタンスの破棄は必ずDisposeフェイズで行い、外部の処理はDispose処理中に破棄予約済みのインスタンスにアクセスすることが禁止されます。
ただし、適切な実装であれば削除予約がされた段階でIDを経由したアクセスができなくなるので不正なメモリアクセスが発生することはありません。
```c++
RenderSceneHandle handle;
if(auto scene = handle.value()){
	// 処理
}
```
このパターンはweak_ptrによるアクセス権の獲得と似ていますが、所有権の獲得は行いません。
Disposeフェイズをまたいでアクセスしない限り、インスタンスは破棄されないため安全にアクセスできます。
ただし、アクセス中に外部から削除予約される可能性があります。
