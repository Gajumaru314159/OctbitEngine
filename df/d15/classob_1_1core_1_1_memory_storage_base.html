template<class T, size_t SIZE, size_t ALIGN>
class ob::core::MemoryStorageBase< T, SIZE, ALIGN >

メモリストレージ

遅延初期化をする場合に使用します。 通常はRAIIに則り生成時に初期化することが望ましいですが、 初期化を遅らせる必要がある場合に使用します。 unique_ptrと違いメンバ変数として使用する場合はクラスのインクルードが必要です。
